Start with the equation:

2n^2 + 2n + 1 = p 

Subtract (p) from both sides to get everything on one side:

2n^2 + 2n + 1 - p = 0 

Factor out the coefficient of (n) (which is 2) from the first two terms:

2(n^2 + n) + 1 - p = 0 

To complete the square inside the parentheses, focus on (n^2 + n).  

Take half the coefficient of (n) half of 1 is 1/2, then square it: (1/2)^2 = 
1/4. 

Rewrite the expression by adding and subtracting (1/4) inside:

n^2 + n = n^2 + n + 1/4 ==> (n+1/2)^2 !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!! FIXME FIXME FIXME !!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

Substitute this back in:

2[(n + 1/2)^2 - 1/4] + 1 - p = 0 

Distribute the 2:

2(n + 1/2)^2 - 2/4 + 1 - p = 0 

Simplify  -2/4 = -1/2:

2(n+1/2)^2 - 1/2 + 1 - p = 0 

Combine the constants -1/2 + 1 = 1/2:

2(n + 1/2)^2 + 1/2 - p = 0 

Move the constant terms to the other side:

2(n + 1/2)^2 = p - 1/2 

Divide both sides by 2:

(n + 1/2)^2 = (p - 1/2)/2

Rewrite the right side with a common denominator:

(p - 1/2)/2 = (2p - 1)/4   or   (p-1/2)/2 * 2/2 ==> (2p -1 )/4

So:

(n+1/2)^2 = (2p - 1)/4

Take the square root of both sides (remembering both positive and negative 
roots):

n+1/2 = sqrt((2p-1)/4) ===> sqrt(2p-1)/2

Then:

n+1/2 = sqrt(2p-1)/2

Subtract 1/2 from both sides:

n = (sqrt(2p-1)/2) - 1/2
