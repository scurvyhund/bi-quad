A simple substitution of n with (m–1) will proof that n^2 + (n+1)^2 + (n+2)^2 equals 3*n^2 + 2 :

n^2 + (n+1)^2 + (n+2)^2 =
(m–1)^2 + ((m–1)+1)^2 + ((m–1)+2)^2 =
(m^2–2m+1) + (m^2) + (m^2+2m+1) =
m^2 + 1 + m^2 + m^2 + 1 =
3*m^2 + 2 QED
And also that n^2 + (n+1)^2 equals 2n(n–1)+1 :
n^2 + (n+1)^2 =
(m–1)^2 + ((m–1)+1)^2 =
m^2–2m+1 + m^2 =
2m^2 – 2m + 1 =
2m(m–1) + 1 QED
