# docs/sources — external artifacts, kept verbatim

Primary sources behind the corroboration in
[`../palindrome_split_search.md`](../palindrome_split_search.md) §7.
Snapshotted 2026-09-05 because they had existed only in a session
temp directory, and because the upstream pages are live and edited.

**These files are not ours and are not to be edited.** Their whole
evidential value is that they share no code, no method and no author
with this project. Correct a transcription in the doc that cites
them, never in the artifact itself — the same reason
`degeest_susq2.txt` stays at 67 of 69 entries.
